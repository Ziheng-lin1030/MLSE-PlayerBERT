# Structure for final report:

# 1. Intro

Should be short. Focus on explaining research question in a succinct manner. No more than 1 paragraph. 

# 2. Data & Data Processing

Be specific. Describe the exact data you used and describe every data processing step. 

# 3. Methods

Describe the methods you used in as little math as possible. For instance, write out the essential equations to describe your approach but do not go into too much detail. Describe the motivation/utility behind each approach. If you used multiple methods, feel free to include a table that describes each approach, e.g. 

<table><tr><td>Model</td><td>Motivation</td></tr><tr><td>Model 1</td><td>Used to...</td></tr><tr><td>Model 2</td><td>Builds on model 1 to further account for...</td></tr></table>

Feel free to include diagrams of the models as well if you find it helpful. 

# 4. Results

Put effort into creating nice visualizations, diagrams, and tables to describe your results. Each should include a descriptive caption. Discuss how the results tie back to answering the research question. 

# 5. (Optional) What comes next?

Optional – if you have included enough detail in parts 1-4 that you feel has fulfilled your task, feel free to skip. However, if there is more you would like to discuss, any approaches you did not have the time to implement but you would have wanted to with additional time and resources, feel free to include this here. 

# 6. For me, as an appendix – technical aspects of the methods you have used, including visualizations.

Create an appendix with all of the technical details not included in the methods section in part 3. 

For instance, include: 

Assumptions behind the data processing steps. 

Describe assumptions behind every model. 

How do the models align with how you processed the data. 

Model & data limitations. 

No code in report unless absolutely relevant. All tables, diagrams, figures, should appear professional.
